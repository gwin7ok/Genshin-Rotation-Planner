# 原神ローテーション ガントチャート (Genshin Rotation Planner)

**公開運用中: https://gwin7ok.github.io/Genshin-Rotation-Planner/**

更新履歴: [CHANGELOG.md](CHANGELOG.md) / [リリース一覧](https://github.com/gwin7ok/Genshin-Rotation-Planner/releases)

出場ターンの直列スナップと、スキル・爆発の CT、バフの重複を確かめるための、原神のローテーション・シミュレーターです。
計算エンジンに [gcsim](https://github.com/genshinsim/gcsim) を使い、編成・ローテーションを gcsim で実行した結果を、ガントチャートに反映します。
