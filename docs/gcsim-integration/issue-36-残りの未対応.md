## 2. 残りの未対応

### A. 全体の注意（値の確からしさ）
1. 未マージ PR（カチーナ・ネフェル・リンネア・アリョーシャ）の値は、作業中・未検証。PR の更新で変わる可能性がある（コミットは固定してある）。ゲームでの実測が要る。
2. ローエン・サンドローネ・ヴォジャニーツァ・ヴェスナのアクションの長さは、推定（同じ武器種の中央値）。実測ではない（誤差の見込み: 0.2〜0.5 秒）。
3. 特殊元素スキル（ローエン・ヴェスナ）の長さは、特殊スキルの中央値 68f の推定。
4. wiki の記述からの値（ローエンの愉悦の命中数・ヴェスナの剣気の増加・カチーナの「乗っている間は 1 秒ごとに夜魂値 10」）は、ゲームでの確認が未了。
5. gcsim では実行できない（キーが無い）。CT・効果の確認は、アプリの計算だけ。gcsim の結果との照合ができない。

## 4. 補足: `GITHUB_TOKEN`（生成スクリプトの GitHub API 認証）
- 対象: `npm run build:master` / `npm run build:master:appside`（Node のスクリプト）。ブラウザ（DB 管理の「最新キャラをオンライン生成」）は、環境変数を読めないため、未認証のまま（1 時間に 60 回まで）。
- 認証すると、1 時間に 5,000 回まで使える。**権限は付けない**（公開リポジトリの読み取りだけ）。
- 設定手順は、チャットで案内したとおり（`gh auth token` を使う方法と、個人用アクセストークンを作る方法）。トークンはリポジトリに入れない・チャットに貼らない。
