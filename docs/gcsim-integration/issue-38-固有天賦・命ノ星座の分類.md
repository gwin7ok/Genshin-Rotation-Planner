# issue #38: gcsim 未実装 9 キャラの固有天賦・命ノ星座の分類（2026-10-11。確定・実装済み。D161）

「ゲームに新キャラが実装されたときの取り込み手順」（docs/ゲーム新キャラの取り込み手順.md の A・D、docs/新キャラ実装時の作業.md の 2・3）の考え方で、9 キャラ × （固有天賦 2 + 命ノ星座 6）= 72 件を分類した。

## 前提（現状）
- 固有天賦 18 件: genshin-db の説明文から、時間（`duration`）を読み取って定義になっている。すべて「gcsim 対象外」（辞書にキーが無い）。時間が無いものは「時間指定のない効果」の行に出る（全体 / 自分だけの判定は、`buffScope.ts` の自動判定）。
- 命ノ星座 54 件: **効果の定義（`constellationEffects`）は 0 件**。命ノ星座の効果の定義は、gcsim の辞書のキーから作るため、gcsim 未実装のキャラには作られない。凸の説明文から読み取った効果時間の延長（`actionChanges`）だけが、確認済みの 4 件（ネフェル凸 2・ローエン凸 6 は対象外の理由つき、ヴォジャニーツァ凸 2・アリョーシャ凸 2 は反映）。

## 分類の記号
- **T** 時間つきの効果 → 発動バフのボタン（時間・条件つき）
- **S（全）** 時間指定のない効果・全体向け（最下行） / **S（自）** 自分だけ（キャラ名の横）
- **M** モード・アクションの計算で反映済み（#36・D160）
- **D** 効果時間の延長（`constellationEffects.ts` の確認済み・対象外の一覧で処理済み）
- **X** 対象外（回復・エネルギー回復・追加ダメージの発生・スキルレベル +3・未実装の数値〔闘争心・負荷値など〕に依存）

## 実装（D161）
決定: 1① 命ノ星座をアプリ側の表で定義にする（`src/masterdata/appSideBuffDefinitions.ts`）／2① 層数・消費で変わる効果は最大層で固定してボタンにする／3① 対象外の固有天賦 4 件は定義から外す／4 リンネア P1 は全体。
全体 / 自分だけは、確認用の一覧（`buff-scope-review.md`）で確認し、ネフェル C4・サンドローネ C1・ヴォジャニーツァ C6・アリョーシャ C6 も全体に上書きした。
未解決: ヴォジャニーツァ P2（メロディ・コーラス）の層の効果（説明文に無い。ゲームでの確認 #37）。

## 決めてもらうこと（回答済み。上の「実装」）
1. **命ノ星座を、効果の定義にする仕組み**: 今は、gcsim の辞書のキーからしか作れない。T・S の約 20 件を、アプリ側の定義（手で書く表）として足すか。足さなければ、命ノ星座のボタンは出ないまま（固有天賦だけ）。
2. **層数・消費で変わる効果**（リンネア C1・サンドローネ P1・ヴェスナ P1・ヴォジャニーツァ C4）の扱い（固定の最大層で出す / ボタンにしない）。
3. **X に分類した固有天賦 4 件**（ネフェル P1 の 15 秒・P2、ローエン P1、アリョーシャ P1）を、定義から外してよいか（説明文のホバー表示だけに残す案もある）。
4. **全体 / 自分だけの修正**: リンネア P1（自分だけ → 全体）。
