# #39〜#45: 他のキャラ・未実装の仕組みに依存して、アプリでは実現できない項目（2026-10-11。D165 時点）

#36 で gcsim 未実装 9 キャラのアプリ側の対応を進めた結果、**自分の操作が引き金になるもの**（時間・CT・状態の期間）は、D154〜D165 で実装した。
ここに残るのは、**他のキャラの操作・元素反応・ダメージ量・チームの属性**に依存する項目、または**仕様のソースが無い**項目。issue に貼る用の整理。

## 実現の見通し
1. **R（元素反応の時刻）**
   - 最も多くの項目が依存している。
   - gcsim が対象キャラを実装すれば、実行結果から入る（反応の行の仕組みは実装済み）。それまでは、手動のボタンで補う。
   - アプリ側で作る場合は、「どのキャラのどのアクションが、いつ、どの反応を起こすか」のモデルが要る。大きな作業。
2. **D（ダメージ量）**: アプリの方針の外。対象外のままにする。
3. **M（月兆）**: 小さい。キャラごとの月兆の属性のデータを足せば、段階の数え方と表示の分岐ができる。必要になれば着手する。
4. **S（ソース無し）**: gcsim の実装・ゲームでの測定を待つ。#37 の確認項目と同じ。

## issue への書き方（案）
> アプリで表せる範囲（自分の操作が引き金になる時間・CT・状態の期間）は、D154〜D165 で実装した。
> 残りは、他のキャラの元素反応の時刻（R）・ダメージ量（D）・月兆の属性（M）・仕様のソース無し（S）に依存するため、いまのアプリのモデルでは表せない。
> gcsim が対象キャラを実装した時点で、実行結果から取り込む（R・S）。D は対象外とする。
> 詳細は docs/gcsim-integration/issue-39-45-実現できない項目.md。
