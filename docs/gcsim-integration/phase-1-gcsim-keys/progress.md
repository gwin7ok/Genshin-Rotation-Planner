## 解決済みの事項

- **I1: 1秒未満の「○秒毎に1回」を効果のCTとして読み取っていた**（2026-09-28 解決、方針 a）
  - 発覚: 再生成で聖顕の鍵の効果CTが 0 → 0.3秒に変わった。生成処理（`equipmentBuffParser.ts` の `extractEquipmentTimings`）が、説明文の「0.3秒毎に1回」（効果を重ねる間隔）をCTとして読み取っていた。コミット 1439a0c の補正辞書 `cooldown: 0` は、説明文が優先されるため効いておらず、マスターデータ JSON の手修正だけで隠れていた。
  - 範囲: 同じ誤りが武器24件（聖顕の鍵を含む）・聖遺物4件にあった。
  - 修正: 最初に見つかったCT表現が1秒未満なら「その効果にCTは無い」とみなし、探索をやめる（`MIN_EFFECT_COOLDOWN_SEC = 1`）。同じ文の後ろの「○秒毎」まで探すと、別の副次効果の間隔（久遠流転の大典のエネルギー回復12秒、山の王の長牙の層獲得2秒）を拾うため、探さない。聖顕の鍵の補正辞書の `cooldown: 0`（効いていなかった回避策）は削除。
  - 結果: 1秒未満のCTが全データから消えた。値が別の値に変わった項目は無い。
  - 副作用: 1秒未満のCTしか情報が無かった2件は、発動バフの定義ごと無くなった（もともと効果時間が空で、正しいバーは出ていなかった）。
    - 狼の武勲詩: 説明文の「継続時間は4秒」を、効果時間の読み取りパターン（「継続時間4秒」形のみ対応）が拾えていない → 全体計画の「関連する未対応事項」に記録。
    - 来歆の余響（4セット）: 実際は0.05秒で消える一瞬の効果。旧形式欄の「効果時間10秒」も誤りだった。
