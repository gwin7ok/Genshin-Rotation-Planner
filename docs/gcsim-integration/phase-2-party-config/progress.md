## 確認結果（2026-09-28）

- **初期状態**（保存データなし）: 4枠とも未設定（`empty_slot_1〜4`）・出場なし・総時間 0.0秒。画面にプリセットの表示なし。
- **編成設定**: ナヒーダを選び、武器「千夜に浮かぶ夢」・聖遺物「深林の記憶」を選択。保存データは `weaponId: "14511"`・`weaponRefinementRank: 1`（星5の初期値）・`artifactSetId: "15025"`・`artifactSetMode` で記録され、`weaponName` / `artifactSetName` は無い。
- **4セット / 2+2**: 4セットでは発動バフ「深林4: 草元素耐性-30%」（補正辞書の ID キーで補正された名前）が出て、2+2 では出ない。説明欄も「2セット効果のみ・発動バフなし」に切り替わる。
- **武器の発動バフ**: 祭礼の断片（ID 14403）で「祭礼の断片: スキルCTリセット」が ID から作られる。
- **名前の重複**: 「一心伝」名刀の3つ（11419 / 11420 / 11421）は選択肢の値が ID なので区別される。
- **補正辞書**: 見出しを公式IDに変換（武器19件・聖遺物15件。日本語名・英語名の重複見出しを統合）。マスターデータを再生成し、更新日時以外は全件同一であることを確認（補正結果は不変。再生成データは更新日時だけの差分のため反映せず）。
- **初期状態に戻す**: 4枠とも未設定・出場なしに戻る。
- 古い形式の保存データ（武器を名前で持つ）を読み込んでもエラーにならない（装備は未設定として表示）。
- 名前で登録・照合している箇所: 残りは gcsim ソースのフレーム表名の解析（外部データの解析のため対象外）のみ。
- コンソールエラーなし。型チェック・ビルド成功。

## 変更内容

- 型: `CharacterConfig` の `weaponName` / `artifactSetName` を削除し、`weaponId` / `artifactSetId` / `artifactSetMode`（`ArtifactSetMode = '4pc' | '2+2'`）を追加。`PartyPreset` 型を削除。
- 編成設定（`PartyConfigModal.tsx`）: 武器・聖遺物の選択値を ID に。「(カスタム入力)」の選択肢を削除。聖遺物に「4セット / 2+2」の選択を追加。キャラ一覧の検索から装備名を外した（DB のキャラは装備を持たないため）。
- 発動バフ（`buffUtils.ts`）・`WeaponModel.findInDatabase`: ID だけで引く。2+2 は聖遺物の発動バフなし。
- 補正辞書（`equipmentBuffOverrides.ts`）と生成処理（`equipmentBuffParser.ts`）: ID キー・ID 参照に。
- キャラの登録し直し（`stintReorder.ts` の `refreshCharactersFromDatabase`）: 装備 ID・精錬ランク・4セット/2+2 を引き継ぐ（精錬ランクは以前から引き継がれていなかった）。
- 記法の交代判定（`rotationNotation.ts`）: 表示名での判定をやめ、`type` / `actionTypeId` だけにした（他の箇所と統一）。
- プリセット削除: `src/data/presets.ts`、プリセット専用の手作業のキャラ定義（`RAW_CURATED_ROSTER` / `ALL_CHARACTERS_ROSTER` / `CURATED_LEGACY_ALIASES`）、保存・読込画面のプリセット選択、`selectedPresetId` / `presetId`（状態・保存項目・JSON 書き出し）。初期状態と「初期状態に戻す」は未設定の編成に。
- 旧キー移行の削除: `resolveLegacyCharacterId`・`migrateCharacterIds`・`legacyCharacterSlug`・`isOfficialCharacterKey`。旧形式のデータ構造の変換（`migrateLegacyCharacter`）は名前ベースではないため残した。

## 見つかった既存の問題（今回の変更によるものではない）

- 補正辞書の CT は実行時（`buffUtils.ts`）に精錬ランクを問わず上書きされる。例: 祭礼の断片は補正辞書が精錬5の値（CT16秒）を持つため、精錬1でも CT16秒（本来30秒）になる。gcsim 連携後は結果ベースになるため、従来の計算を残す場合のみ修正が必要 → 全体計画の「関連する未対応事項」に記録。
- 千夜に浮かぶ夢など、効果時間・CT の無い常時効果の武器は発動バフを持たない（生成処理の仕様）。
