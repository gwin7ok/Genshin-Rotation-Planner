## 確認結果（2026-09-28）

- **マスターデータ**: 全127キャラが1〜6凸の段階データ（名前・説明文）を持つ。効果時間の延長は11キャラ分が該当段階の `actionChanges` に入った（例: 香菱4凸 `10000023-pyro_q` 10秒 → 14秒）。「(n凸)」の別アクション11件は削除。コミット済みデータとの比較で、ほかの差分はイルーガのみ（gcsim 側に実装されたため、gcsim のフレームと gcsim キーが付いた。外部データの更新による正しい変化）。
- **DB の置き換え**: バージョン11・凸データなしの保存DBを読み込むと、バージョン12になり、ロックしていないキャラは凸データ付きのマスターに置き換わった（126/127）。ロック中のキャラは既存の方針どおり上書きされない（凸データは付かない）。
- **編成画面**: 香菱（星4）を選ぶとキャラカードの凸数が6凸、ナヒーダ（星5）は0凸。設定欄に1〜6凸の名前・説明が出て、凸数までの段階が強調され、4凸に「元素爆発: 旋火輪: 効果 14s」が表示される。
- **時間計算**: 香菱の旋火輪の効果バーは 0〜3凸で10秒、4凸・6凸で14秒、凸数未設定（既定値6凸）で14秒。
- コンソールエラーなし。型チェック・ビルド成功。

## 変更内容

- 型（`src/types/genshin.ts`）: `ConstellationLevel`・`CharacterConstellationData`・`ConstellationActionChange` を追加。`CharacterConfig.constellations`（マスター）を追加。`constellation` に説明（0〜6、既定値）を追記。
- 生成（`src/masterdata/constellationEffects.ts` を全面書き換え、`characterMasterGenerator.ts`）:
  - genshin-db の凸データの突き合わせ: 通常キャラは **ID**（凸データの id = （公式キャラID - 10000000）× 100 + 1。天賦と同じ規則。120/122キャラで一致を確認、残り2は凸の無いドール）。旅人は元素ごとの別エントリを「旅人 (風元素)」の形で判別（天賦の処理と同じ。外部データの例外）。
  - `applyConstellationVariants`（別アクションの追加）を `buildConstellations`（段階データの作成）に置き換え。確認済み規則・対象外一覧の見出しをキャラ名から**キャラID**に変更（D13）。
  - レポートを `constellations`（凸データのキャラ数・反映した延長・未確認・エラー）に変更。ビルドスクリプトの出力も対応。
- DB バージョン: 11 → 12（`src/data/databaseMaster.ts`）。
- 解決役（新規 `src/models/CharacterModel.ts`）: 凸数（未指定なら星4=6・星5=0）、`activeConstellations`、凸の変更を累積適用した `actions`。`defaultConstellation` / `MAX_CONSTELLATION` を公開。
- 置き換え: 時間計算（`rotationCalculator.ts`）、出場ごとの操作画面（`StintSequenceEditor.tsx` のアクション定義の参照・追加ボタン）。キャラ入れ替えの対応付け（`stintReorder.ts`）は種類と ID だけを使うため変更なし。アクション追加時に効果時間はコピーされず、計算時に定義から引くため、凸数を変えると即反映される。
- 「(n凸)」ラベルの処理（`characterActions.ts`）を削除。
- 編成画面（`PartyConfigModal.tsx`）: キャラカードを、中に選択欄を置けるよう `button` からクリック可能な `div`（role=button、Enter/Space 対応）に変更し、右下に凸数の選択（0〜6凸）を追加。キャラを選んだときに初期値を設定。設定欄に命ノ星座の一覧を追加。
