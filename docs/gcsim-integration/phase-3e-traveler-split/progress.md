## 確認結果

- `npm run build:master`: 134 キャラ（旅人 14 + 通常 120）。空・蛍とも `aether<元素>` / `lumine<元素>` の gcsim キー、アイコン `PlayerBoy` / `PlayerGirl`、6段の凸、2件の固有天賦。`_aether` / `_lumine` のアクション ID は 0 件
- 空・蛍でフレームが別（例: 風の N 0.283s / 0.4s、水の E 45f / 44f）
- `tsc --noEmit`・`npm run build` 成功
- 起動中の gcsim サーバーの `/validate` で、`aetherhydro` / `luminehydro` の `skill[hold=1,hold_ticks=1]` を含む設定文が通ることを確認（サーバーの再ダウンロードは不要だった）
- 生成時の警告: 風の `e_hold` が空・蛍とも「フレーム定義なし（仮の秒数）」、旅人(岩)6凸の効果時間延長が「未確認」（フェーズ3b からの残り事項。空・蛍の2キャラ分に増えた）
