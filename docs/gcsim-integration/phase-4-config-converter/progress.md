## 確認結果

2026-09-29（利用者の確認待ち）
- gcsim v2.47.6 の `server_windows_amd64.exe`（49,627,136 バイト）を取得して起動し、`/validate` に設定文を送った。エラーなしで解析され、キャラ・武器・精錬・聖遺物・凸数・天賦・仮ステータスが期待どおりに読み取られた。
- 参考に `/sample`（seed=1）も実行し、実際に動くことを確認した（約4,000件のログ）。アクションは設定文の順に実行され、`delay(6)` が各アクションの後に入り、キャラ交代が自動で行われる。ニィロウの E×4（`skill` 4回: 初回＋ステップ）も実行された。
- 使った編成: エクスポート済みの「豊穣月開花」（ナヒーダ・ニィロウ・コロンビーナ・ラウマ）。
- 副産物: この編成は、2周目の先頭でニィロウのスキルが CT 待ちになる（19.93s〜21.10s、`could not execute skill; action not ready` が連続）。D21 の想定どおりに、`event=sim` のログでCT待ちを検出できることを確認した。
- 警告の確認（Node）: gcsim キーの無いキャラ、変換規則の無いアクション、N2 単独（直前が N1 でない）、出場ブロックなし、未設定枠のみ、のいずれも期待どおりの error / warn が出て、error があれば `runnable=false` になる。
- 確認後、サーバーを停止し、ダウンロードしたファイルを削除した。
