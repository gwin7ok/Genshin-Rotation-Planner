# スキル・爆発のモードを最大時間まで維持する設置（分類と実装計画）

作成: 2026-10-05（ユーザーの指示。分類は確定、実装計画は検討中）

## 1. 仕様（ユーザー決定）
アプリでスキル（E）・爆発（Q）が置かれたとき、そのモードが、**ゲーム上、最大時間まで持続する形**で設置する。
そのために、gcsim の仕様に合わせて、アプリ側で必要なアクションを置く（`wait` を入れる、E の継続時間を延ばす、など）。

## 2. 分類（確定）

## 3. 実装計画（案）
### 3-1. 方針
モードの最大時間を、「出場の最後の後の自動の待機」として、計算結果に出す。保存はしない（計算で毎回出す）。
- 出場の最後のアクションの後に、モードが残っていれば、残りの時間だけ、自動の待機を、出場の長さに足す（表示: 「モード維持」のブロック）。
- gcsim の設定文は、その待機を `wait(...)` として出す（既存の `extraWaitByActionId` の仕組みを使う）。
- 途中で終了させたいときは、終了のアクション（A-1・D-1 は、E 再押し・ジャンプなど）を置く。または、その出場の「モード維持」を切る。

### 3-2. 変更の範囲
1. **マスターのデータ**（モードの定義）: トリガーのアクション（E/Q/長押し E）、最大時間、開始の遅れ、終了のアクション（種別）、交代で終わるか。既存の `burstMode`（ディシア）を、一般化する。
2. **計算**（`rotationCalculator.ts`）: モードの窓を、一般の仕組みにする（開く・終了のアクション・出場の終わりで切る）。出場の終わりに、残りの時間を「モード維持」の待機として足す。
3. **gcsim の設定文**: 自動の待機を、`wait(...)` で出す。結果の反映（所要時間の書き戻し）で、待機を含めて、gcsim の実測に揃える。
4. **B（長押し）**: 長押しの `hold` の既定値を、最大にする。リネット・藍硯に、`hold=<フレーム数>` の変換を足す（早柚・綺良々は対応済み）。
5. **画面**: 「モード維持」の表示、出場ごとの切り替え（維持する／しない）。
6. **警告**: モードの間に置けない操作（夢見月瑞希の通常攻撃など）。

### 3-2. 段階
1. 仕組み + 夢見月瑞希（A-1）+ ディシア（D-1。既存のモードを移行）。
2. A-2・D-2 を、データの追加で展開（キャラごとの値の確認）。
3. B（長押し）。
4. 警告・画面の切り替え。

### 3-3. 決めたい点
- 既定を「維持する」にすると、これまでの並びは、E の後、最大時間まで出場が延びる（出場全体の時間が変わる）。切り替えの単位（出場ごと／アクションごと／全体）。
- 交代のフックがないキャラ（クロリンデ・放浪者・閑雲・アロイ）は、gcsim では、交代しても状態が続く。維持の待機を自動で入れるか。
- スカーク（点が尽きる 6.4 秒）など、最大時間が条件で変わるキャラの時間の取り方（上限／実効）。
- 命ノ星座・固有天賦による延長（夢見月瑞希 10 秒、ディシア 6 など）を、時間に含めるか。

## 4. モードを最大時間まで維持するために置くアクションの形（2026-10-05 整理）
基本の式: 自動の待機 = max(0, モードの終わり − 出場の最後のアクションの終わり)。モードの終わり = トリガーのアクションの開始 + 開始の遅れ + 最大時間。出場に、モードの間に置いたアクションがあれば、その分を引く。

| 形 | 対象 | アプリの並び（例） | gcsim の設定文（例） | 途中終了 |
|---|---|---|---|---|
| α 状態の維持 | A-1・A-2・D-2（魈・サイノ…）| `E` → 待機（自動）→ 交代 | `char skill; wait(N); next swap;` | 交代、または A-1 の終了のアクション（E 再押し・落下攻撃） |
| β 自動の動作を待つ | D-1（ディシア） | `Q` → 待機（自動。パンチ 6 発 + 蹴りが終わるまで）→ 交代 | `dehya burst; wait(N); next swap;`。入力を置けば、N・E がパンチ（27〜30f）になる | ジャンプ（ダッシュ → ジャンプは蹴り）、交代 |
| γ 長押しの長さ | B（早柚・綺良々・リネット・藍硯） | 長押し `hE` 1 つ（長押しの長さ = 最大） | `char skill[hold=<最大フレーム数>];` | 長押しを短くする（hold の秒数を減らす） |
| δ 連鎖 | 閑雲（跳躍 3 回） | `E E E` → 最後の跳躍の状態が終わるまで待機 | `skill; skill; skill; wait(N);` | 落下攻撃で終了 |
