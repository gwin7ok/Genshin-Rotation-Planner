## 対象

## 調査方法

gcsim v2.47.6 のローカルサーバー（localhost:54321）で、90 件を単独キャラ（凸0・仮の武器・敵1体）で実行。
- スキル定義: ①2回（10秒あけ）②5連続 ③スキル→通常攻撃3→重撃→通常攻撃2→スキル→通常攻撃3
- 爆発定義: 爆発だけ（爆発→通常攻撃3→10秒待つ→爆発→通常攻撃2）。**先にスキルを実行するとスキルの効果が混ざる**ため、爆発の判定は「爆発だけ」の条件のみを使う
- 基準: 通常攻撃3＋重撃だけの実行で出るイベントは除外。武器・ダッシュの状態、内部のCT（`icd`・`particle`）も除外
- 見たイベント: 状態（added/refreshed/extended）・設置物・シールド・回復・継続ダメージ
- 注意: 重撃が未実装のキャラ（大剣・弓など 16 件）は③が実行できない（①②は実行できる）。反応（拡散・蒸発など）を起こす条件では実行していない。ただし、この 68 キャラの効果は対応表ですべて紐づけ済みか理由つきの決定済みで、未検討 0 のため、反応由来で新たに見つかる余地は小さい
