## 結論（先に）

- 54 件の内訳: 命ノ星座 **51**（CT のキー 44・効果のキー 7）、固有天賦 2（ディシア・レザー。CT のキー）、武器 1（蛇の脊椎。CT のキー）。命ノ星座・固有天賦は、**同じ凸・同じ枠に、マスターの定義が無い**（A「既存の定義に CT を付けるだけ」は 0 件）。
- 理由: マスター生成は、命ノ星座の定義を「**時間つきの効果が 1 つ以上ある凸**」にしか作らない（`buffGcsimLink.ts` の `s.timing !== 'computed'` の分岐で、CT だけ・常時・時間が分からない凸は定義にしない）。これらの 54 件は、その凸の効果が「CT 付きの即時・条件つきの効果」のため、定義が無く、CT の付け先が無い。
- つまり、**①だけを独立して進める（定義を増やさずに結び付ける）ことはできない**。付けるには、**「CT だけを持つ・時間の無い命ノ星座の効果」の定義を作る**必要がある。これは、作業 ②（6-A2: 定義を持たない常時効果の扱い）と同じ設計の話になる。
