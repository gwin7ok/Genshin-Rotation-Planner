# Phase 3-1c 検証レポート（3編成脱落原因根治 ＋ 追撃トリガーN精密化 ＋ 国際タルタリヤ実戦ビルド）

## 1. 強ローテ 3 件の脱落トレース原因と修正内容

| 編成 | トレースで判明した脱落原因 | 実施した修正 |
| :--- | :--- | :--- |
| 雷電ハイパー (42.0k) | `ベネット(slot 10)` と `楓原万葉(slot 20)` の `slot` 差により、`knowledgeSeeds` が `万葉→ベネット→裟羅` の順を 0 件しか生成していなかった。 | 楓原万葉 `#0: E→落下→Q` の `slot` を `20 → 10` に変更し、`万葉→ベネット` と `ベネット→万葉` の両順がシード生成されるように修正。 |
| フリーナ蒸発 (84.4k) | 編成 4 人が全員 `supporter`/`subAttacker` のため、`knowledgeSeeds` の `if (attackers.length === 0) return [];` でシードが **0 件** になっていた。 | `variantsOf()` で `attackers.length === 0` のときは `slot` 最大メンバーを暫定アタッカー扱いしてシードを組むフォールバックを追加。 |
| 刻晴激化 (77.3k) | ① `ナヒーダ[tE]` だけだと万葉スキル CT(6s) に届かず CT 違反になる一方、兼任キャラ（ナヒーダ `attacker+supporter`）の `attacker` 型がシード枠を圧迫していた。② `万葉[N]` 単独初動や `N×2 C` が無差別に生成されていた。 | ① 専任 `attacker` がいる編成では兼任キャラの `attacker` 型を後回し化。② `canSupporterUseFreeNormal` と `canSupporterUseTriggerNormal` を分離し、`newN` は西風/法器アタッカー限定、追撃トリガー編成のサポーター `n` は `e/e_hold/q` 同居 Stint に 1 回のみペナルティ 0 で許可（`N×2`/`ca` 置換・挿入は禁止）。 |
