# Phase 3-1d Early Priming（早期反応起動ロジック対応 ＋ サンドローネ初動 E 復帰）検証結果

## 1. 実装・更新内容
- **`src/utils/rotationSearch/candidates.ts` (`neighborsOf`)**:
  - **初動スキル先置き `newE` の追加**: `loop === 0` の候補に対し、ループ先頭と異なるキャラで `e` を持ち、基本 CT ≤ 12 秒または効果持続 ≥ 18 秒のスキルを `loopStartIndex = 1` で先頭配置する近傍を追加。
  - **法器初動 `newN` の精密化**: 単独 `N` 初動を「西風武器装備」または「水・草・氷・雷の法器キャラで直後の出場キャラと別元素（即座に初回反応を起動可能）」のみに限定。
- **`src/utils/rotationSearch/search.ts` (`rankScoreOf`)**:
  - `loopStartIndex > 0` の単独 `N` 初動ペナルティについて、水・草・氷・雷の法器キャラが直後に別元素キャラへ繋ぐ早期反応起動の場合は `× 0.990`（-1.0%）から `× 0.998`（-0.2%）へ緩和（無意味な単独 `N` 初動は `× 0.990` のまま、初動 `E` はペナルティ 0）。
- **`src/masterdata/knowledge/characters.ts`**:
  - サンドローネ（`10000133-cryo`）の `#0` および `#1` に `lead: ['e']` を追加し、`node scripts/build-knowledge.ts` で `public/knowledge/` を再生成。
- **`docs/genshin-mechanics/character-gimmicks-system.md`**:
  - 1.4 節に「時間蓄積型ギミックの早期反応起動（Early Priming）」として月開花・星電導の初動指針を追記。
