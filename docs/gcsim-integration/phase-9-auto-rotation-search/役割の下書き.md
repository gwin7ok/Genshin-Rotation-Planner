# 役割の表（アタッカー / サブアタッカー / サポーター）

作成: 2026-11-20 / 状態: **確定（2026-11-20。マスターデータの初期値にした: `src/masterdata/characterRoles.ts` → キャラの `roles`）**。表を直したら、`characterRoles.ts` も直して `npm run build:master`、`npm run check:roles`

原神 Wiki（https://wikiwiki.jp/genshinwiki/ の各キャラのページ「考察 → 総評」）の文章から Claude が判断した下書きを、ユーザーが直したもの。
**3 種の定義**（ユーザー決定 2026-11-20）:
- **アタッカー**: 表で攻撃アクション（通常攻撃や重撃）を起こすことでダメージを出す役。サブアタッカーの連係攻撃を発動するドライバー役も含む
- **サブアタッカー**: 設置物や、表のキャラの通常攻撃などに連動する連係攻撃などで、裏からダメージを出す役
- **サポーター**: ヒーラー・シールダー・裏からの元素付着役

役割は、**3 つの列（アタッカー・サブアタッカー・サポーター）に、当てはまるものすべてに ✔ を付ける**（複数可）。以前の「両対応」は、アタッカー ＋ サポーター の 2 つに ✔ を付けて表す。
単独 DPS（千単位。`npm run probe:solo-dps`）は、参考値。「持ち」は、持ちキャラの実際の装備での値（持っていないキャラは「-」）。単独では反応が起きないので、反応で稼ぐキャラは低く出る。
「根拠」は、総評の要点を Claude の言葉で短くしたもの（Wiki の文章は写していない）。「前回の下書き」は、Wiki を読む前に付けた 3 種類（アタッカー / 両対応 / サポート）。
