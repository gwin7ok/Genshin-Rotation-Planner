# 役割の下書き（アタッカー / サポート / 両対応）

作成: 2026-11-20 / 状態: **下書き（ユーザーの確認待ち）**

原神 Wiki（https://wikiwiki.jp/genshinwiki/ の各キャラのページ「考察 → 総評」）の文章から、私（Claude）が判断した。
判断の基準: 総評が「メインアタッカー」「アタッカー」と書くものは**アタッカー**。「サブアタッカー」「サポーター兼サブアタッカー」「アタッカー／サポーター」など両方を挙げるものは**両対応**。「サポーター」「バッファー」「ヒーラー」「シールダー」だけのものは**サポート**。
単独 DPS（千単位。`npm run probe:solo-dps`）は、参考値。「持ち」は、持ちキャラの実際の装備での値（持っていないキャラは「-」）。単独では反応が起きないので、反応で稼ぐキャラは低く出る。
「根拠」は、総評の要点を私の言葉で短くしたもの（Wiki の文章は写していない）。
**違うものは、「役割」の欄を直してください。**
