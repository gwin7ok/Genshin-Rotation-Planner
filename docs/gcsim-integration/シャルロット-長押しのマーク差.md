# シャルロット: 長押しのマーク差（gcsim 未実装）と長押し探索の留意事項

## ゲーム内の仕様
- 1 回押し、および最大ズームしていない長押し: 敵に「スナップシルエット」のマークを付ける。
- 最大ズーム時の長押し: 敵に「フォーカスインプレッション」のマークを付ける。

## gcsim の現状（2026-11 確認。`G:\Cursor_Folder\gcsim\internal\characters\charlotte\skill.go`）
- `hold` が 0 のときだけ短押し（`skillPress`。`skillPressMarkKey`）。
- `hold` が 1 以上なら、長さに関係なく常に `skillHold`（`skillHoldMarkKey` ＝ フォーカスインプレッション相当）。
  `skillHoldMarkTargets` は長さを見ない（見るのは `markCount == 5` と敵かどうかだけ）。
- 長押しの長さ（1〜809f）は、着弾（`hold + 111f`）・CT 開始・後隙にしか影響しない。判定ボックスは固定（ズームの範囲差なし）。
- つまり「最大ズームしていない長押し（スナップシルエット）」は gcsim で再現できない。`hold=1` でもフォーカスインプレッションになる。

## アプリ（自動探索）の方針
- シャルロットの長押しは、長さ違いの近傍を作らない（`HOLD_FRAMES_ACTIONS` に載せない）。短押し（`e`）と長押し（`e_hold`）の 2 択だけを探索する。
- 長押しは、最大ズームの長押し（フォーカスインプレッション）として扱う。

## gcsim が対応したときの留意事項
1. ズームの段階（最大ズームか否か）で、付くマークが変わるようになったら、長押しの探索を「短押し / ズームなし長押し / 最大ズーム長押し」の 3 択に増やす。
2. 最大ズームに必要な長押しのフレーム数（閾値）を、gcsim の実装から確認する。
3. `HOLD_FRAMES_ACTIONS`（`src/utils/gcsim/actionMapping.ts`）に載せるか、アクション定義を分ける（雲菫・シグウィンの `shorthold` と同じ形）かを決める。
4. `buildGcsimConfig` の長押しの渡し方（`applyHoldSeconds`）と、`parseGcsimConfig` の逆変換（`holdSecondsFromCommand`）を合わせる。
5. 近傍探索（`neighborsOf` の長押しの長さ）は、「ズームなし」「最大ズーム」の 2 つの代表値だけにする（中間の長さは DPS に影響しない）。
6. `npm run check:snapshots` で差分を確認する。
