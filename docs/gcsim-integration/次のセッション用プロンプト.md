- 状態の間だけ変わる通常攻撃などのフレームは未対応（神里綾人の瞬水剣・魈の爆発中・ニィロウの剣舞の N・フレミネの爆発中・雷電将軍の夢想の一太刀など）。クロリンデ（狩りの N・爆発）だけ対応済み（`ActionMode.normalFrames`・`burstFrames`）。gcsim の結果を反映すると、所要時間は実測になる。
