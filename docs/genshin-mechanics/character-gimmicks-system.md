## 1. 地域・キャラ固有リソースのローテーション前提

### 1.1 命の契約（Bond of Life）
| キャラ | 仕組み | 正しいローテ構造 | やってはいけない不自然パターン |
| :--- | :--- | :--- | :--- |
| **アルレッキーノ** | `E` で敵に血償の勅令を付与 → **5秒経過後に重撃 `CA`** で回収すると命の契約 130% 獲得（即回収だと 65% のみ）→ 炎付与の強化通常（`N3D` 推奨）で消費。`Q` は命の契約を消して回復＋`E` CTリセット。 | **前半 `slot 10: E` で勅令付与 → サポーター3人回し（5秒稼ぎ）→ 後半 `slot 40: CA → N3D×n`**。毎周 `Q` を撃つ必要はない（緊急回復・リセット用）。 | 同じ出場内で `E → 即CA` してしまう（契約量半減）、あるいは `CA` 後にすぐ `Q` で契約を消してしまう。 |
| **クロリンデ** | `E`（夜巡り・7.5秒）中、通常3回（射撃）で命の契約が 100% 以上になり、`E`（穿夜・突進）が最大強化される。 | **`E` → (`N×3 → E`) の繰り返し（最大5〜6セット）**。`Q` はスキル前後に挟む。 | `N` を1〜2回だけで `E` を連打する、または `E` を挟まず `N` だけ連打する。 |
| **シグウィン** | 長押し `E` で源水の雫生成＋命の契約を獲得・クリアしてエネルギー回復。 | 基本は `E_HOLD` だけ（火力型のみ `Q`）。 | 毎周無駄に長い `Q` を撃ってDPSを落とす。 |

### 1.2 夜魂の加護・夜魂値・戦意（ナタ系）
| キャラ | 仕組み | 正しいローテ構造 |
| :--- | :--- | :--- |
| **シロネン** | `E` で夜魂状態に入り、**通常攻撃 2 回（`N×2`）**で夜魂値満タン→サンプル音源起動（耐性 -36%・15秒）。 | **`E → N×2`** が絶対必須（`E` だけではデバフが発動しない！）。`Q` は回復が必要なときのみ。 |
| **シトラリ** | 夜魂値 50 以上で「イツパパ」が白曜状態になり**控えから継続氷付着**。凍結・溶解反応でさらに夜魂値回復＆炎/水耐性 -20%。 | `E → Q`（または `E → N → Q`）で夜魂値 50 以上を確実に確保して退場する。 |
| **マーヴィカ** | **元素エネルギーが存在せず「戦意」（上限200・100以上で発動）**で爆発。チーム内の夜魂値消費と通常攻撃命中で戦意蓄積。 | ナタキャラ（シロネン・シトラリ・イアンサ等）で夜魂消費してから `Q` → 重撃回転（`CA`）または `E` 控え炎付着。 |
| **ムアラニ** | `E`（波乗り）中に敵へ接触して3層溜め → **強化通常攻撃（噛みつき）を最大3回**。各噛みつきの間に炎下地が必要。 | `E` 後に3回噛みつき（合間に下地確認）＋ `Q`。 |
| **キィニチ** | `E`（懸狩り）中、自動旋回射撃と**燃焼／烈開花反応**で夜魂値を急速蓄積し、20溜まるごとに「廻狩貫鱗砲（`E`）」を発射（最大4〜5発）。 | 炎＋草で燃焼維持 → `E` → (`N` 挟み＋貫鱗砲 `E`)×4〜5回。 |
| **ヴァレサ** | `E → N → 落下攻撃` を 2 セット行うと「極限ドライブ」に入り、エネルギー消費の少ない**特殊元素爆発**を即撃ちできる。 | `(E → N → 落下) × 2 → 特殊Q` の繰り返し。 |
| **イアンサ** | `E → N（または重撃） → Q` で攻撃力バフ。出場キャラの**移動量**に応じて夜魂値を維持。 | `E → CA/N → Q`。 |

### 1.3 HP増減・テンション・源水の雫（フォンテーヌ系）
- **フリーナ**: `Q`（持続18s）中にチーム全体の HP が増減するとテンション上昇→全体ダメバフ。**`E` の自傷は HP 50% 以上でないと止まる**ため、全体回復ヒーラー（白朮・閑雲・ジン・早柚・シャルロット・エスコフィエ等）と組む場合は `フリーナ Q` の直後に全体回復を挟むとテンションが一気に溜まる。
- **ヌヴィレット**: 強化重撃（`CA`・約3秒）は「源水の雫」を **3個消費して即発動**する。
  - 雫の生成数：**`E` で 3個（CT 12s）、`Q` で 6個（CT 18s）**。
  - したがって 1 ローテ（約22〜26秒）で `E×2（6個）＋ Q（6個）＝ 計12個` → **強化重撃 4 回**、あるいは `E（3個）＋ Q（6個）＝ 9個` → **3 回** にちょうど収支が合うように `E`→サポート更新→`CA→Q→E→CA`→サポート更新→`CA×2` と分割出場するのが王道。
- **リオセスリ**: 0凸は HP 50〜60% ライン管理で `N3C` / `N5C`、1凸は通常5段命中または2.5秒経過で強化重撃が確定発動するため `N5C` ループが基本。

### 1.4 月反応・草露（Ver.5.8〜Luna Ⅳ）＆ 星反応・負荷値（Luna Ⅷ〜Ver.7.x）
- **月開花＆草露（コロンビーナ / ラウマ / ネフェル等）**: 水＋草で「草露」を獲得し、それを消費して高火力の「月開花扱いダメージ」（コロンビーナ重撃連打・ラウマ長押し `E`・ネフェル特殊重撃）を撃つ。ラウマは草露を溜めてから `E_HOLD` を使うため、水・草付着が済んだ中盤〜後半（`slot: 30`）に配置するのが強い。
- **月感電（イネファ / フリンズ等）**: 水＋雷で雷雲を生成。フリンズは特殊スキル→特殊爆発ループ。
- **月結晶（兹白 / イルーガ / リンネア等）**: 水＋岩で月籠を生成。
- **星電導・負荷値（サンドローネ / ニコ / 八重神子 / 北斗等）**: サンドローネは重撃（`CA`）で「負荷値」が上がり、`E` でリセットする循環（`C→E→Q→C→E→C→E`）。Luna Ⅷ 強化で八重神子は `Q` で殺生櫻が破壊されず、北斗は重撃でも追撃が発生し氷耐性ダウンを持つ。
- **時間蓄積型ギミックの早期反応起動（Early Priming）**:
  - **月開花**: 草露の獲得レートに時間上限があるため、ローテ極力前半で初回開花を起こすことが重要。元素量消費（草下地への水は 0.5 倍消費で草が残りやすい）の観点から、基本は「草先付着（`ナヒーダ[tE]` 等）→ 水」が最優だが、構成次第で水法器の初動 1 手 `N`（`コロンビーナ[N]`）も早期起動として有効。
  - **星電導**: 早期に超電導→星電導フィールド・スタックを立ち上げるため、長モーションの `八重神子[E×3]` 等の前に短 CT 氷スキル（`サンドローネ[E]` 等）を初動配置すると、早期フィールド展開＋氷粒子生成の両面で有利。

## 2. 通常攻撃「モーション判定」vs「ダメージ判定」＆ 追撃互換マトリクス

探索ロジックや編成相性で最も間違いやすいのが**「どの追撃がどのアタッカーの攻撃に連動するか」**の違い。

| 追撃ソース | 発動トリガーの厳密な条件 | 雷電 `Q`（抜刀） | ヌヴィレット `CA` / 一斗 `CA` | 胡桃 `N1C`（通常1→重撃） | サポーターの `N` 1手 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **行秋 `Q`（雨簾剣）** | 通常攻撃の**モーション開始**（空振りでも発動、CT 1s） | **○** | ×（重撃のみ不可） | **○**（`N1`で発動） | **○**（水付着トリガー可） |
| **夜蘭 `Q`（擲骰）** | 通常攻撃の**モーション開始**（CT 1s） | **○** | × | **○** | **○**（水付着トリガー可） |
| **フィッシュル 6凸（オズ追撃）** | 出場キャラの通常攻撃**モーション** | **○** | × | **○** | **○**（ナヒーダ草下地からの雷拡散トリガーに多用） |
| **トーマ `Q`（熾炎崩破）** | 通常攻撃の**モーション**（CT 1s） | **○** | × | **○** | **○** |
| **北斗 `Q`（閃雷）** | 通常・重撃の**ダメージ命中**（※Luna Ⅷ 魔導強化時は重撃も含む） | **×**（雷電抜刀は爆発ダメ扱い） | 強化時/通常は要確認 | **○** | **○**（命中時） |
| **アルベド `E` / 千織 `E` / ナヒーダ `E` / 雷電 `E`** | 敵への**任意のダメージ命中**（ナヒーダは反応トリガー） | **○** | **○** | **○** | **○**（スキル命中でも可） |
| **ディシア `E` / マヴィカ `E` / フリーナ `E`** | 敵ダメージ命中 / 自動間隔攻撃 | **○** | **○** | **○** | 任意の攻撃で可 |

> **→ 探索ルールへの反映**:
> - `canSupporterUseTriggerNormal(party)` の対象は **行秋・夜蘭・6凸フィッシュル・トーマ・北斗**（通常攻撃で控え追撃が出るキャラ）。
> - これらが編成にいるとき、サポーター Stint 内で **`e`/`e_hold`/`q` と同居する 1 回だけの `n`**（例：`万葉[N tE hP]`、`香菱[N Q E]`）は正当な元素付着／追撃トリガーとしてペナルティ 0 で許可する。

## 3. 反応競合・編成縛りのルール

- **凍結＋破砕（氷砕き）**: 凍結状態の敵に両手剣攻撃・岩攻撃・落下攻撃を当てると凍結が解除されて破砕が発生する（氷風4の会心率+40%が剥がれる原因）。
- **開花の草原核上限**: 場上に同時存在できる核は最大 5 個、同一敵への開花ダメージ判定は **0.5秒間に最大 2 回**（ICD相当のダメージ上限）。
- **編成元素縛りの天賦**:
  - **ニィロウ（豊穣の核）**: 水＋草のみ（他元素が1人でも混ざると固有天賦が完全無効化）。
  - **シュヴルーズ（炎雷耐性 -40%）**: 炎＋雷のみ。
  - **エスコフィエ**: 水＋氷の人数に応じて水・氷耐性ダウン最大 -55%。
  - **スカーク**: 水＋氷のみ（チーム構成依存の倍率強化）。

## 4. モーションキャンセル・ヒットストップ・CT同期の理論

### 4.1 キャンセル種別と使い分け
| キャンセル種別 | 用途・特徴 | 代表例 |
| :--- | :--- | :--- |
| **ダッシュキャンセル（`D`）** | 最も速い後隙消し。スタミナ消費あり（連打すると枯渇）。 | フリーナ `E D`、香菱 `Q E D`、行秋 `E D`、1凸胡桃 `N2CD`、アルレッキーノ `N3D`、宵宮 `N5D`、雷電 `N4D` |
| **ジャンプキャンセル（`J`）** | ダッシュより僅かに遅いが**スタミナを消費しない**。 | **0凸胡桃 `N1CJ`**（重撃でスタミナを大量消費するためダッシュ不可）、クレー重撃キャンセル |
| **交代キャンセル（`swap`）** | 行動の硬直をキャラ交代で消す。スタミナ不要。 | サポーター全般のスキル／爆発直後の即交代 |

### 4.2 ヒットストップ（Hitlag）
- 近接攻撃（片手剣・両手剣・長柄武器）が敵に命中すると数フレーム動作が停止し、**自キャラのバフ・モード持続時間（雷電 `Q`、胡桃 `E`、綾人 `E` 等）も同時に停止して実質的に延長**される（弓・法器はヒットストップなし）。
- そのため、近接アタッカーの実戦コンボ時間は理論フレーム合計より 0.5〜1.5 秒ほど長くなるのが正常（`hitlag_frames.json` / gcsim が処理）。

### 4.3 クールダウン（CT）開始タイミングと標準ローテーション周期
- **発動時 CT 開始**（大多数のキャラ）：スキルを押した瞬間に CT カウント開始。
- **終了時 CT 開始**（要注意）：**タルタリヤ `E`（滞在時間 + 6秒）**、**フィッシュル `E`（オズ退場時ではなく発動時25s、ただし `Q` 切替で実質カバー）**、**早柚 `E_HOLD`（転がり終了時から最大11s）**、**バーバラ/七七 等**。
  - タルタリヤや早柚のように滞在時間がそのまま次周の CT に跳ね返るキャラは、**出場時間を伸ばしすぎると次周で CT 待ちが発生してローテ全体が崩壊**する。
- **標準ローテ長を決めるボトルネック CT**：
  - **15s 帯**: 刻晴激化（刻晴 Q 12s / 万葉 E 6s / ナヒーダ Q 13.5s）
  - **18s 帯**: 雷電 Q 18s（実戦はヒットストップ込み 20〜22s）、放浪者、クロリンデ、アルハイゼン
  - **20〜21s 帯**: 香菱 Q 20s、行秋 Q 20s / E 21s、フリーナ E 20s、ベネット Q 15s、国際タルタリヤ（約20〜22s）
  - **24〜26s 帯**: ヌヴィレット（2回出場分割）、セノ（爆発持続最大18s）、エウルア

> **→ 探索・辞書設計ルール**:
> - 辞書では `use` に固定30手をべた書きせず、**`fill`（コンボ周期テンプレート）＋ `fillCount`（回数レンジ）＋ `lead`/`tail`** で記述することで、編成のボトルネック CT（15s / 18s / 21s / 24s）に合わせて探索エンジンが最適な滞在時間に伸縮できるようにする。
