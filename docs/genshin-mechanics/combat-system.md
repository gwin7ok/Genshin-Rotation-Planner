## 1. 元素量（GU）・元素付着・ICD（付着クールタイム）

### 1.1 元素付着と元素付与の違い
- **元素付着（Aura）**: 敵または自キャラに元素が乗っている状態。別元素の攻撃が当たると元素反応が発生し、一定の消費係数に従って付着元素が消費される。
- **元素付与（Infusion）**: 武器による物理攻撃が元素ダメージに置換される状態（刻晴固有天賦、ディルックQ、完凸ベネットQ、重雲E、キャンディスQ等）。
  - ※完凸ベネットの炎付与や重雲の氷付与は、**「表で殴るアタッカー／ドライバーの攻撃を元素化する」ためのもの**であり、控えサポーター自身が通常攻撃を振る根拠にはならない。

### 1.2 ICD（元素付着クールタイム）
- 標準ICDは **「2.5秒 または 3ヒット」**（2.5秒以内に3ヒットしても2.5秒タイマーはリセットされずヒット数のみリセット）。
- 例外として **ICD無し（毎回付着）** の技は反応頻度・下地維持に決定的な影響を持つ：
  - 香菱 `E`・`Q`、胡桃の重撃、落下攻撃全般、八重神子 `Q`（初撃＋天狐雷霆最大4連付着）、刻晴 `E` 雷楔、ナヒーダ `E` 滅浄三業（**1.5U・ICD無し**）等。

### 1.3 下地消費と「2元素同時拡散」「ナヒーダ草下地問題」
1. **水炎 2 元素同時拡散（例：国際タルタリヤ）**
   - タルタリヤ `E`（双剣切替ダメージ）は **2U 水付着**。
   - ベネット `Q` は **2U 炎攻撃** だが、水下地への炎蒸発は消費係数が **0.5倍** のため、蒸発後も**敵に水元素が残留**する。
   - 続いてベネット爆発エリア内で楓原万葉が `Q` / `E` を打つと：
     1. 最初の風攻撃で敵の残留**水元素を拡散**（翠緑水デバフ＋万葉水ダメバフ）し、敵の水を消費し切る。
     2. ベネット爆発の「自キャラ炎付着」＋万葉の元素変化優先順（**炎 ＞ 水 ＞ 雷 ＞ 氷**）で、万葉のスキル落下／爆発が**炎元素に変化**して敵に炎付着。
     3. 続く落下攻撃（乱れ嵐斬）や爆発継続ダメージの風付着で**炎元素を拡散**（翠緑炎デバフ＋万葉炎ダメバフ）。
   - **重要結論**: 国際タルタリヤで「ベネットQ → 万葉」の順が王道なのは、この水炎2元素同時拡散を成立させるため。ベネットを万葉より後ろ（香菱直前）に下げると、タルタリヤへのベネットバフ時間は伸びうる一方、万葉の炎拡散（翠緑炎デバフ＋炎ダメバフ）が不安定または不成立になるトレードオフがある。

2. **ナヒーダ 1.5U 草下地による雷拡散阻害 ＆ オズ追撃トリガー `N tE`**
   - 原激化中に雷攻撃で超激化が起きると「雷＋激化元素」の二重下地になり、通常なら風キャラで雷拡散できる。
   - しかしナヒーダ `E`（滅浄三業）は、元素反応トリガーで **ICD無し 1.5U の草追撃** が即座に発生するため、二重下地に対して原激化＆草激化を同時発生させ、**雷元素を完全に消費して「激化元素＋草」に上書き**してしまう。
   - 対策として実戦では、ナヒーダ追撃 CT 中に **出場した風キャラ（万葉・スクロース等）が `E`/`Q` の直前に `N` を 1 回だけ振る** → **6凸フィッシュルのオズ通常連動追撃で雷を再付着** → 直後に `tE` で**雷拡散を通す**（例：`万葉[N tE hP]`）。

> **→ 探索・辞書設計ルール**:
> - 通常連動追撃キャラ（6凸フィッシュル・行秋・夜蘭・北斗・トーマ等）がいる編成では、サポーター Stint 内で **`e`/`e_hold`/`q` と同居する 1 回だけの `n`** を正当なトリガー手として許可・ペナルティ 0 にする。
> - 逆に、追撃キャラがまだスキル/爆発を出していない場面の単独 `N` 初動（`newN`）や、同一 Stint 内での `N×2`・`CA` 挿入は禁止／減点する。

## 2. 元素反応の体系（Ver.7.x / Luna Ⅷ 時点）

### 2.1 増幅・激化・拡散・転化（従来反応）
- **増幅反応（蒸発・溶解）**: 炎→水 / 氷→炎は **1.5倍**（下地消費0.5倍で下地が残りやすい）、水→炎 / 炎→氷は **2.0倍**（下地消費2.0倍で一撃高火力だが下地が消えやすい）。
- **激化（原激化 → 超激化 / 草激化）**: 原激化状態は草・雷の攻撃を受けても激化元素量が減らない（炎・水を入れると消費される）。手数とICD管理（例：刻晴 `N1C` 3ヒットループ）が重要。
- **拡散（翠緑の影4セット）**: 拡散させた元素の敵耐性 -40%（10秒）。**装備キャラが表にいるときのみ発動**（控えからの風攻撃では翠緑4が発動しない）。

### 2.2 月反応（Ver.5.8〜Luna Ⅳ）＆ 星反応（Luna Ⅷ〜Ver.7.0）
| 反応 | 組み合わせ | 特徴・ローテ設計上の注意点 |
| :--- | :--- | :--- |
| **月感電** | 水＋雷 | 雷雲を生成し継続雷ダメージ（反応ダメージあり＋扱いダメージ）。イネファ・フリンズ・コロンビーナ等。 |
| **月開花** | 水＋草 | 草原核生成＋「草露」を獲得。**反応自体には反応ダメージが存在せず**、キャラ側の「月開花ダメージ扱い」スキル/重撃（コロンビーナ重撃・ラウマ等）が主力。 |
| **月結晶** | 水＋岩 | 「月籠」を生成し反応ダメージ＋扱いダメージ。兹白・リンネア・イルーガ等。 |
| **星電導** | 氷＋雷 | スターライトプリズム生成・極星フィールド展開。**反応自体に反応ダメージは存在せず**、キャラ側の「星電導扱いダメージ」（サンドローネ等）が主力。輝映・魔女の諭示で八重神子（爆発で殺生櫻を破壊しない）・北斗（重撃でも追撃・氷耐性ダウン）等の挙動が変化。 |
| **星拡散** | 氷＋風 | 星の嵐を生成し氷追加範囲ダメージ（反応ダメージあり＋扱いダメージ）。サンドローネ・オデット・夢見月瑞希・氷旅人等。 |

- **月兆（初照 / 満照）**: 聖遺物「月を紡ぐ夜の歌4」等は控えからでも元素ダメージ命中で熟知＋月反応バフを起動可能。

> **→ 探索・辞書設計ルール**:
> - 翠緑4装備の風キャラは必ず表で対象元素を拡散させる順序にする。
> - 八重神子（Luna Ⅷ強化）は爆発で殺生櫻を破壊しなくなったため、古い前提の「必ず `E×3→Q→E×3`」に縛られず、`E×3` 維持や単発 `Q` 挟みも有効な選択肢として扱う。

## 3. スナップショット vs リアルタイム参照（バフ順序の原則）

### 3.1 スナップショットする技（発動時点のステータスを終了まで固定）
- **代表例**: 香菱 `Q`（旋火輪）、フィッシュル `E`（オズ）、北斗 `Q`、ウェンティ `Q`、甘雨 `E`/`Q`、神里綾華 `Q`、綺良々 `Q` 等。
- **ローテへの影響**: ベネット `Q` の攻撃力バフ、旧貴族4、九条裟羅の攻撃力バフ、武器/聖遺物のステータスバフは、**スナップショット技の発動直前に必ず掛ける**必要がある（発動後に掛けても乗らない）。

### 3.2 スナップショットされないバフ・技（リアルタイム参照／後乗せ有効）
- **敵へのデバフは常に後乗せ有効**: 翠緑4の耐性ダウン、鍾離シールド耐性ダウン、防御ダウン等。
- **ステータス画面に出ない特殊バフはスナップショット不可（リアルタイム参照）**:
  - フリーナ `Q` ダメバフ、夜蘭 `Q` ダメバフ、申鶴の氷翎加算、**九条裟羅 6 凸の雷会心ダメ +60%**（攻撃力バフと違い6秒間リアルタイム）、ステータス非反映の武器効果等。
- **リアルタイム参照の代表技**: 雷電将軍 `Q`（夢想の一心）、神里綾人 `E`（瞬水剣）、夜蘭 `Q`、行秋 `Q`、八重神子 `E`（殺生櫻）等。
  - **ローテへの影響**: 持続の短いバフ（九条裟羅6秒・ベネット12秒等）は、リアルタイム参照アタッカーの**直前**に配置するほど恩恵が最大化する。

> **→ 探索・辞書設計ルール**:
> - サポーターの `slot` 設計の基本順：`持続の長い設置/バフ(slot 10)` → `スナップショット系サブアタッカー(slot 20)` → `持続の短い直前バフ/再拡散(slot 30)` → `表アタッカー(slot 40)`。

## 4. 元素エネルギー・元素粒子・特殊ゲージ

### 4.1 粒子1個あたりのエネルギー基礎回復量（× 受取キャラのチャージ効率）
| 粒子の種類 | 出場キャラ（表） | 控えキャラ（4人PT＝60%） |
| :--- | ---: | ---: |
| **同元素粒子** | **3.0** | **1.8** |
| **無属性粒子（西風武器）** | **2.0** | **1.2** |
| **無属性粒子（敵HP/撃破）** | **2.5** | **1.5** |
| **異元素粒子** | **1.0** | **0.6** |

- **粒子生成 0 のキャラ**: バーバラ・ノエル・七七は `E` で粒子を生成しない（バッテリーになれない）。
- **バッテリー渡し（Funneling）**: `ベネット[E] → 即 香菱` のように、粒子飛来前に交代して同元素の重い爆発キャラに表（3.0×ER）で回収させるテクニック。
- **西風武器**: 装備キャラが**表で会心ヒット**させたときのみ無色粒子×3生成（控え発動不可）。会心判定を稼ぐため `E→N` や `Q→N` の 1 手 `N` が合理的になる。
- **固定値回復（チャージ効率が乗らない）**: 雷電 `Q` の夢想の一心による全体回復（雷電自身のERで増幅、受取側ERは不適用）、タルタリヤ弓 `Q` の **20返還**（消費60→実質40）、九条裟羅パッシブ2、セノ等。

### 4.2 非エネルギー型・特殊リソース型キャラ
- **マーヴィカ**: 元素エネルギーではなく「戦意」（チーム内の夜魂消費・通常攻撃命中で蓄積）。
- **スカーク**: 元素エネルギーなし。
- **サンドローネ**: 重撃で上昇する「負荷値」を `E` でリセットする循環構造（`C→E` 交互・`C→E→Q`）。

> **→ 探索・辞書設計ルール**:
> - 指定周数（例：5周）を完走できずエネルギー待ちで打ち切られる（`truncated`）ローテは、1周目（開始満タン）の貯金だけで高DPSに見える偽最適解なので必ず強ペナルティ／除外する。
> - 1周あたりの `energyWaits` が長いローテを減点する一方、探索テスト時は実戦的な ER ビルド（聖遺物4セット＋実用チャージ）で検証しないと「省爆発ローテ」が最適解になってしまう。

## 5. 代表的な行動仕様・キャンセル・CT ルール

### 5.1 モード切替・特殊コマンド
- **タルタリヤ**:
  - `E` で双剣（近接）モードへ移行し、交代または再 `E` で弓に戻る。双剣 CT は **`双剣滞在時間 + 6秒`**（強制解除で45秒）のため、1周の滞在はベネット爆発終了（約7〜9秒）までに抑えるのが鉄則。
  - **重要（gcsim 変換仕様）**: 弓モード中の `ca` は `aim`、双剣モード中の `ca` は `charge`（かつ直前に `attack(n)` が必須）。
  - 弓 `Q` はエネルギー20返還＋水付着、近接 `Q` は高倍率だが返還なし（消費60）。
- **雷電将軍**:
  - `E` は持続 25秒・CT 10秒でチーム全員の爆発ダメバフ＆追撃。**「1周目だけ先頭で `雷電[E]`（`lead: ['e']`）→ 2番目からループ開始 → 雷電の爆発コンボ終了後に `E` で締める（`tail: ['e']`）」** が願力・バフ維持・CT管理のすべてで最効率。
  - 夢想の一心（抜刀中）の通常/重撃は「通常攻撃モーション＋爆発ダメージ扱い」のため、**行秋・夜蘭の追撃は発動するが、北斗爆発（通常/重撃命中判定）は発動しない**。
- **フリーナ / 香菱 / 行秋 / 胡桃等のキャンセル**:
  - フリーナ `E→DASH`、香菱 `Q→E→DASH`、行秋 `E→DASH` は後隙フレームを実際に短縮できるため、gcsim でも実戦でも正当な短縮テクニック。
  - 胡桃 `N1CJ` / `N2CD`、宵宮 `N5D`、アルレッキーノ `N3D`、雷電 `N3C` / `N4D`、刻晴 `N1C` などは、**固定べた書きではなく `fill`（周期テンプレート）** として表現する。

### 5.2 命ノ星座で「ローテーション構造自体が変わる」代表例
KQM-DB は星4を6凸前提で回すため、凸条件は**実際にアクション構造が変わるキャラ・項目にだけ限定付与**する：
- **ファルザン 6凸**: 爆発中に自動風圧崩潰＋粒子生成が起きるため、`E→CA` を省いた `Q` 単体運用が可能。
- **九条裟羅 2凸**: `E` 発動位置に自動で烏羽設置されるため、重撃（`CA`）を省いた `E→Q` 運用が可能（粒子は出ない点に注意）。
- **シュヴルーズ 4凸**: 爆発後に長押し `E` の CT リセット（最大2回 → `Q→E_HOLD×2〜3`）。
- **藍硯 6凸 / リネット 4凸 / 夜蘭 1凸 / 魈 1凸 / 申鶴 1凸**: 元素スキル使用回数 +1（1出場内 `E×2`）。
- **凝光 2凸**: 璇璣屏破壊で `E` CT リセット（`E→Q→E`）。
- **フリーナ 6凸**: スキル後 6 回まで通常/重撃が水付与＋全体回復・高倍率化（オンフィールド重撃コンボ）。
