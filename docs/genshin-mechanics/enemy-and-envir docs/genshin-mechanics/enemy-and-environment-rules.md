## 1. 戦闘モード差：深境螺旋 vs 幽境の激戦（開始エネルギー 0 問題）

| 項目 | 深境螺旋（標準） | 幽境の激戦（Stygian Onslaught） |
| :--- | :--- | :--- |
| **開始エネルギー** | **全員満タン（100%）** | **全員 0 からスタート** |
| **初動（1周目）の設計** | `lead` は 1 手（雷電 `E`・サンドローネ `E`・アルレッキーノ `E` 等）で即フルバースト可能。 | **1周目から爆発が撃てない**。全員のスキル回し・西風粒子・バッテリー渡しでエネルギーを溜める「初動セットアップ区間（長い `lead`）」が必須。 |
| **爆発依存キャラへの影響** | セノ・香菱・雷電・フリーナ・コロンビーナ等が 1 周目から最大出力。 | 初動火力が大幅低下。**スキル主体アタッカー**や**非エネルギー型（マーヴィカ戦意・スカーク）**、**短CTスキル＋低コスト爆発キャラ**の優位性が跳ね上がる。 |
| **装備トリガーの罠** | 金珀・試作や旧貴族4が開幕即起動。 | 開始エネルギー 0 のため**金珀・試作などの爆発連動チャージ補助が初動で起動しない**。西風シリーズ・祭礼シリーズによる開幕粒子生成の価値が激増。 |

> **→ 探索設計への示唆**:
> - 「開始エネルギー満タン（螺旋）」と「開始エネルギー 0（幽境）」では、同じ 4 人編成でも `loopStartIndex` より前の初動（セットアップ）の最適解が根本的に異なる。

## 2. 元素量（GU）の正確な消費倍率と「ボス凍結の罠」

### 2.1 反応別の下地消費倍率（攻撃元素量に対する倍率）
| 元素反応 | 下地元素の消費倍率 | ローテ設計上の意味 |
| :--- | :---: | :--- |
| **蒸発（水→炎 2.0倍）・溶解（炎→氷 2.0倍）** | **× 2.0** | 一撃火力は最大だが下地が一発で消えやすい。 |
| **蒸発（炎→水 1.5倍）・溶解（氷→炎 1.5倍）** | **× 0.5** | 下地が残留し連続反応が可能（例：タルタリヤ2U水＋ベネット2U炎でも水が残留）。 |
| **開花 / 月開花（水→草）** | **× 0.5** | **草下地が残留し連続開花が可能**（ナヒーダ `tE` 先付着が水先付着より優位な根拠）。 |
| **開花 / 月開花（草→水）** | **× 2.0** | 水下地が一発で消費されやすい。 |
| **拡散・結晶** | **× 0.5** | 通常は下地が残留しやすい。ただし**鍾離/雲菫の4U岩（2U消費）やウェンティの2U風（1U消費）**は下地を消し切る場合がある。 |
| **過負荷・超電導・凍結** | **× 1.0** | 等倍消費。凍結は少ない方の元素量×2が「凍結元素」として付着。 |

### 2.2 単体ボス vs 複数雑魚（ウェーブ戦）の違い
1. **ボスへの凍結は「元素消費だけ起きて凍結元素が付着しない」罠**
   - 通常敵：水＋氷で凍結元素が付着し、氷風4（+40%）・氷共鳴（+15%）・拡散元として機能する。
   - **凍結無効ボス**：凍結表示が出て**水・氷の両元素が消費されるのに、凍結元素は一切付着しない**。
   - 結果、ボス相手に水・氷を混ぜると**敵の付着元素が丸ごと消滅**し、氷風4の会心率・氷共鳴・星拡散（拡散元消失）の恩恵が大きく落ちる。
2. **撃破粒子と HP 閾値粒子**
   - 複数雑魚戦は敵撃破時の無色粒子/オーブが大量に出るため ER 要求が緩い。
   - 単体ボス戦は撃破粒子 0（HP 閾値粒子のみ）のため、**ER 要求が最も厳しくバッテリー渡し（Funneling）の有無が DPS を左右する**。
3. **複数戦・ウェーブ切替で評価が大きく変わるキャラ**
   - **複数戦で激増**: 北斗 `Q`（2体以上で跳弾最大、単体ではDPS半減）、タルタリヤ（断流連鎖）、万葉/ウェンティ/スクロース（集敵＋連鎖拡散）、ニィロウ開花（核の範囲重複）。
   - **ウェーブ切替に弱い**: ナヒーダ `E`（蘊種印の張り直し必須 → セノ等の長時間居座りアタッカーは途中交代できないためウェーブ戦が苦手）、翠緑4・深林4（新ウェーブで再付与必要）。

## 3. 敵の耐性・防御力・元素シールド

### 3.1 耐性ダウンの半減ルールと高耐性ボス
- 敵の標準全耐性は **10%**。
- **耐性 0% 未満の領域では耐性ダウン効果が半減**する（例：耐性 10% に翠緑 -40% → `-15%`、さらにシロネン -36% → `-33%`）。
- 逆に、ギミック中や高耐性ボス（70%〜210%：秘源機兵・統御デバイス、深罪の浸礼者等）では、耐性ダウンのダメージ上昇率が劇的に跳ね上がるため、**翠緑4・シロネン・シュヴルーズ・エスコフィエ・鍾離** の優先度が上がる。
- **防御ダウン／防御無視**（リサ -15%、雷電2凸 60%無視、ナヒーダ2凸 -30%、クレー2凸 -23% 等）は耐性ダウンとは別枠で乗算される。

### 3.2 元素シールド削りの原則
- 敵の元素シールド（例：アビス魔術師 雷 8U / 炎・水・氷 12U、深罪の浸礼者 同等）は**ダメージ量ではなく元素付着量（GU）× 消費倍率**で削れる。
- **ICD 無し高頻度付着**（香菱 `Q`、ベネット 2U `E`/`Q`、タルタリヤ 2U `E`、行秋/夜蘭の多段水、ナヒーダ 1.5U 草）が最速。
- **氷シールドの注意点**：氷シールドは凍結と同じ挙動をするため**水・草元素では削れない**（炎が2倍効率で最速）。逆に水シールドには草（2倍）・氷（凍結等倍）が有効。

## 4. gcsim シミュレーションと実ゲーム挙動の既知の差異（探索結果の解釈ガイド）

自動探索は gcsim を使って DPS を比較しているため、以下の「gcsim 側の理想化」を前提に結果を読む・チューニングする必要がある：

| 項目 | gcsim の前提（理想化） | 実ゲームでの注意点・探索への反映 |
| :--- | :--- | :--- |
| **敵の攻撃・被弾・回避** | 敵は基本かかし（被弾・ノックバック・回避による中断なし）。 | シールド（鍾離・レイラ・藍硯等）や中断耐性（行秋・ディシア・北斗・ヌヴィ1凸）の価値は純粋 DPS に出にくい。宵宮 N5D やアルレッキーノ等は実戦では中断耐性枠が実質 DPS を守る。 |
| **操作精度・キャンセル速度** | フレーム単位の完璧なダッシュ/ジャンプ/交代キャンセル。 | 人間では再現不可能な非周期コンボ（`N C N N D C`）や +0.2% だけ稼ぐゴミ手は、探索側の**文法ガード＋クリーンアップパス（オッカムの剃刀）**で排除する。 |
| **位置取り・エリア移動・粒子飛来** | 敵は動かず常に全攻撃が範囲内命中。粒子飛来距離も一定。 | ベネット/ロサリア等の円エリア外への敵移動や、粒子キャッチ時のわずかな待ち時間は実戦で誤差になる。 |
| **仮値ビルド（`default_builds.json`）の ER** | 聖遺物サブステ・ER が未最適化な仮値で CLI テストされる場合がある。 | ER 不足のビルドで探索すると「省爆発ローテ」が物理的に高 DPS になる（国際タルタリヤの香菱 ER210% かつバッテリー渡し無しで 58s 待ちになる等）。異常に低い探索 DPS が出たら、**まず `energyWaits` とビルド ER を確認する**こと。 |
