# 原神 主要チームアーキタイプ別 ローテーション設計プレイブック

- 目的: 個別の元素反応・キャラ仕様だけでなく、「4人編成全体としてどういう順番・周期・粒子回しで組むのが王道か」「自動探索が陥りやすい不自然な落とし穴は何か」を編成タイプ別に整理する。

---

## 1. 国際蒸発（タルタリヤ・香菱・ベネット・万葉）
- **標準周期**: 20〜22s（ボトルネック: 香菱 Q 20s / タルタリヤ双剣 CT＝滞在+6s）
- **王道構造**:
  `タルタリヤ[E](2U水) → ベネット[Q](2U炎・水残留) → 万葉[tE hP Q](水炎2元素同時拡散) → 香菱[Q E](スナップショット) → タルタリヤ[Q(弓・20返還) E N2CD×3〜4] → ベネット[tE] → 香菱(粒子回収)`
- **探索上の重要ポイント**:
  - **2元素同時拡散**: ベネット Q の自キャラ炎付着を万葉より先に出すことで水・炎を同時拡散。
  - **バッテリー渡し（Funneling）**: 香菱（必要80）はベネットの2回目 `E` の炎粒子を直接受け取らないと高ER（210%超）でも爆発が回りにくい。
  - **タルタリヤ滞在制限**: 双剣滞在を7〜9秒で切り上げないと次周 `E` の CT が破綻する。弓 `Q` 先撃ちはエネルギー20返還で回転が劇的に良くなる。

## 2. 雷電ハイパー（雷電・九条裟羅・万葉・ベネット）
- **標準周期**: 21〜23s（ボトルネック: 雷電 Q 18s＋ヒットストップ / 九条裟羅 Q 20s）
- **王道構造**:
  `雷電[E](初動) → ↻万葉[tE hP Q] → ベネット[tE Q] → 九条裟羅[E C Q](直前6秒バフ) → 雷電[Q N3C×3 E](末尾E締め)`
- **探索上の重要ポイント**:
  - **初動E＋末尾E締め（`lead: ['e']` / `tail: ['e']`）**: 雷電 E（持続25s）を切らさず願力と爆発バフを最大化。
  - **九条裟羅の直前配置**: 攻撃力バフ・6凸雷会心ダメ+60%は持続6秒のリアルタイム参照のため、必ず雷電の直前（`slot: 30`）で 1 回出場にまとめる（3回細切れ出場は不自然）。

## 3. 雷電ナショナル（雷電・行秋・ベネット・香菱）
- **標準周期**: 21〜23s（ボトルネック: 行秋 E 21s / 香菱 Q 20s）
- **王道構造**:
  `雷電[E](初動) → ↻ベネット[tE Q] → 行秋[Q N E D N] → 香菱[Q E] → 雷電[Q N3C/N4D E]`
- **探索上の重要ポイント**:
  - ベネット Q 上で香菱 Q をスナップショットし、行秋雨簾剣（持続18s・2凸）を雷電抜刀（通常モーション判定○）と噛み合わせる。

## 4. 激化・超激化（刻晴 / 八重 / クロリンデ ＋ フィッシュル ＋ ナヒーダ ＋ 万葉）
- **標準周期**: 15〜18s（短周期・クイックスワップ適性高）
- **王道構造**:
  `フィッシュル[E/Q] → ナヒーダ[tE (Q)] → 万葉[N tE hP (Q)](オズ追撃1手Nで雷再付着→雷拡散) → 雷アタッカー`
- **探索上の重要ポイント**:
  - **ナヒーダ 1.5U 草下地問題**: ナヒーダ E の直後は雷が消えやすいため、6凸フィッシュル入り編成では万葉の `N tE`（1手 N トリガー）が必須級に強い。
  - **禁止すべき崩れ**: オズ召喚前の単独 `万葉[N]` 初動や、`万葉[N×2 C tE]` のような過剰な通常/重撃。

## 5. フリーナ蒸発・テンション編成（フリーナ ＋ 全体回復ヒーラー ＋ 蒸発/アタッカー）
- **標準周期**: 20〜22s（ボトルネック: フリーナ E 20s / Q 15s / 香菱 Q 20s）
- **王道構造**:
  `フリーナ[E D](先置き自傷開始) → 下地/サブ → フリーナ[Q] → 全体回復ヒーラー[Q ...] → 表主力`（または `フリーナ[E D Q] → 全体回復 → サブ → 表主力`）
- **探索上の重要ポイント**:
  - フリーナ `E D`（ダッシュキャンセル）は実際に後隙を大幅に短縮する正当テクニック。
  - `フリーナ Q` の直後に全体回復（早柚/閑雲/ジン/白朮/シャルロット等）を置くとテンションが一気に跳ね上がる。

## 6. 月開花（コロンビーナ / ニィロウ / ナヒーダ / ラウマ 等）
- **標準周期**: 19〜21s
- **王道構造**:
  `早期開花起動（草先付着 ナヒーダ[tE] または ニィロウ[E N×2 E] → 水）→ コロンビーナ[E Q] → ラウマ[(N) hE Q](草露消費) → コロンビーナ[C×4〜5]`
- **探索上の重要ポイント**:
  - **Early Priming（草露の獲得レート上限）**: 早い段階で開花を起動することが重要。元素量消費（草下地への水は0.5倍消費で草が残留）の観点からは草先付着が最優。
  - ラウマの長押し `E` は草露が溜まった中〜後半（`slot: 30`）で撃つ。

## 7. 星電導（サンドローネ / 八重神子 / ニコ / 七七 等）
- **標準周期**: 21〜24s
- **王道構造**:
  `サンドローネ[E](初動：短CT氷スキルで早期星電導＋氷粒子) → ↻八重神子[E×3] → サポート(ニコ/七七) → サンドローネ[C E Q C E C E]`
- **探索上の重要ポイント**:
  - **Early Priming**: モーションの長い `八重神子[E×3]` の前に短 CT の氷スキルを初動配置（`lead: ['e']` / `newE`）することで、星電導フィールドとスタックを最速起動＋氷粒子回収できる。
  - Luna Ⅷ 強化で八重神子 `Q` は殺生櫻を破壊しない。

## 8. ヌヴィレット ハイパー（ヌヴィレット ＋ フリーナ ＋ 万葉 ＋ シロネン / 鍾離）
- **標準周期**: 24〜26s（雫 12 個・重撃 4 回の 3 分割出場が王道）
- **王道構造**:
  `ヌヴィレット[E](雫3・水付着) → フリーナ[E D Q] → 万葉[tE hP] / シロネン[E N×2] → ヌヴィレット[CA Q E CA] → 万葉/シロネン再デバフ → ヌヴィレット[CA×2]`
- **探索上の重要ポイント**:
  - ヌヴィレットの 3 回出場は「細切れノイズ」ではなく、**源水の雫（E3+Q6+E3=12）と翠緑/シロネン 10〜15s デバフの中間更新を両立する必須構造**。
  - シロネンは必ず `E N×2`（`N×2` なしではサンプル音源が起動せず耐性ダウン 0）。

## 9. 命の契約（アルレッキーノ蒸発/モノパイロ、クロリンデ激化/過負荷）
- **アルレッキーノ（18〜20s）**: `アルレッキーノ[E](先置き勅令) → サポート3人回し(5秒経過) → アルレッキーノ[CA(130%回収) N3D×4〜6]`。同一出場で `E→即CA` や `CA→Q`（契約消去）はNG。
- **クロリンデ（16〜18s）**: `サポート → クロリンデ[Q E (N×3 E)×5〜6]`。スキル 7.5 秒中は `N3E` の固定周期を維持。

## 10. 凍結（神里綾華 / スカーク / 申鶴 / 万葉 / 心海 / エスコフィエ）
- **標準周期**: 20〜21s（ボトルネック: 綾華 Q 20s / 心海 E 20s）
- **探索上の重要ポイント**:
  - 綾華は `DASH→(N)→E→Q→N2C` で氷付与＆霧切スタックを確保。両手剣/岩/落下による破砕（凍結解除）に注意。
  - 申鶴の氷翎は 1 ローテ 2 回 `E`（前半 `E→Q`＋後半 `E`）で消費回数を倍増させる形が定番。

## 11. 過負荷（シュヴルーズ ＋ 炎/雷アタッカー ＋ サブ）
- **標準周期**: 18〜20s（炎・雷キャラのみで編成必須）
- **探索上の重要ポイント**:
  - 過負荷を先に起こしてマグナムブレットを獲得してから **`シュヴルーズ[Q E_HOLD]`**（4凸以上は `Q E_HOLD×3`）を撃つ順序が重要。

## 12. ナタ夜魂・戦意編成（マーヴィカ / シトラリ / シロネン / ベネット / ムアラニ / キィニチ / ヴァレサ）
- **標準周期**: 18〜20s
- **探索上の重要ポイント**:
  - マーヴィカはエネルギー不要（戦意100以上）。シロネン `E N×2` → シトラリ `E Q`（夜魂50起動＋氷下地）で戦意を満タンにしてからマーヴィカ `Q` で溶解一撃→重撃回転。
  - 絵巻 4 装備のナタサポートは、必ずバフ対象元素が付着した状態で反応を起こす順番にする。
