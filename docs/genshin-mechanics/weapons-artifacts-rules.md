# 原神 武器・聖遺物のローテーション制約データベース

- 照合元: `https://wikiwiki.jp/genshinwiki/`（武器 / 聖遺物各ページ、2026年11月時点）
- 目的: 武器や聖遺物の発動条件・持続時間・交代制約によって「最適な出場順」「サポーターの `N`/`CA`/`E×2` の正当性」が変わるルールを定義し、探索エンジン・辞書設計の誤判定を防ぐ。

## 2. 特定のアクション（先手 `N` / `CA` / `E×2` 等）を正当化する武器

探索エンジンの「不自然なアクション排除（クリーンアップ・ペナルティ）」で**誤って削ってはいけない**武器固有の行動：

| 武器 | 発動条件 | 正当化される行動パターン |
| :--- | :--- | :--- |
| **西風シリーズ**（西風剣・西風長槍・西風猟弓・西風大剣・西風秘典） | **表で会心ヒット**時に無色粒子×3生成（CT 6〜12s、控え発動不可） | ・サポーターの `E→N` / `Q→N`（スキル1ヒットで会心が出なかった場合の保険・粒子回収用の `N` 1〜2回）<br>・先頭での粒子生成用 `N` |
| **祭礼シリーズ**（祭礼の剣・祭礼の弓・祭礼の断片・祭礼の大剣） | **表で元素スキル命中**時に確率でスキル CT リセット（CT 16〜30s、控え発動不可） | ・同一出場内の **`E→E` 連続使用**（行秋 `E→DASH→E→Q`、万葉 `E→HP→E→HP`、ディオナ `E_HOLD×2` 等）<br>・※これは凸効果ではなく武器効果。 |
| **冬極の白星**（弓） | 通常・重撃・スキル・爆発が命中するごとに独立して「白夜極星」層を獲得（最大4層・12秒） | ・タルタリヤ等で爆発前に **`N` や `CA` を1回挟んで層を乗せてから `Q` を撃つ**行動（先手 `N`/`CA` はゴミ手ではない）。 |
| **霧切の廻光**（片手剣） | ①通常攻撃で元素ダメージを与えた時、②爆発発動時、③エネルギー100%未満で各1層（最大3層） | ・神里綾華（ダッシュ氷付与→`N`→`Q`）や刻晴（`E×2→N→Q`）等で、**爆発直前に元素通常攻撃 `N` を1回挟む**行動。 |
| **蒼古なる自由への誓い**（片手剣） / **終焉を嘆く詩**（弓） | 蒼古：元素反応2回で起動（0.5s毎、控え可）<br>終焉：スキル/爆発命中4回で起動（0.2s毎、控え可） | ・起動までのヒット数／反応回数を満たすために `E→Q` 順や `N` 挟みが選ばれることがある。 |
| **白辰の輪**（法器） | 装備キャラが**表で**雷関連反応を起こすと該当元素ダメバフ（6秒） | ・控え発動不可。法器サポート（スクロース・リサ・心海・ナヒーダ等）が表で雷反応を起こす必要がある。 |
| **匣中滅龍 / 螭龍の剣** | 螭龍：出場4秒毎にダメバフ層（最大5層） | ・螺旋/幽境1間目の初動で1番手に配置して層を溜める運用がある。 |

## 3. 探索エンジン・辞書設計への適用ルール
1. **装備依存の行動は「辞書へのハードコード凸条件」と混同しない**：
   - 祭礼による `E×2` に凸制限（`constellation.min`）を付けてはならない。
2. **クリーンアップパスでの保護**：
   - `isFavoniusWeapon(c.weaponId)` が `true` のサポーターは `E→N` や `Q→N` の `N` を無条件にペナルティ対象にしない。
   - 冬極の白星・霧切の廻光装備のアタッカーは、爆発直前の先手 `N` / `CA` が実際に DPS を上げるためそのまま評価を通す。
3. **TTDS（龍殺し）装備時**：
   - もし探索で TTDS 装備サポーターがいる場合、`slot: 30`（アタッカー直前）の配置候補が必ず残るようにする。
