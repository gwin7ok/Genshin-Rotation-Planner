# 用語集（日本語 → 英語）

英訳は、この表に合わせる（D254）。ゲーム用語は、ゲームの公式英語（genshin-db の English）に合わせる。
新しい用語が出たら、訳す前にここへ足す。「確認」欄が `要確認` のものは、ユーザーの確認を待つ。
